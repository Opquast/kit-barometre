# Baromètre qualité des sites

Ce projet mesure des sites web selon les 245 règles Opquast V5. Pour l'installer et le lancer, lire d'abord `.claude/skills/barometre-sites/INSTALLER-AVEC-UN-ASSISTANT-IA.md`, puis suivre `.claude/skills/barometre-sites/SKILL.md`.

Règles absolues : rien n'est installé sans l'accord explicite de la personne ; sites en lecture seule (aucune commande, aucun formulaire envoyé, aucun compte créé) ; aucun contournement d'anti-robot ; aucune donnée personnelle dans les résultats.
